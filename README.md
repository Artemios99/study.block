# Study Blocker

A simple Chrome extension that blocks distracting websites during focused study sessions.

## Features
- Set a custom focus timer
- Block selected websites while focusing
- Live countdown in the popup

## How it works
Built with vanilla JavaScript, HTML, and CSS using the Chrome Extensions API (Manifest V3).

## Installation (dev mode)
1. Clone this repo
2. Go to `chrome://extensions`
3. Enable Developer mode
4. Click "Load unpacked" and select this folder
